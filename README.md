# ⚡ Energy Scout — поиск энергетиков по магазинам Актобе

Скрипт обходит сайты физических розничных сетей Актобе, собирает энергетические
напитки (Monster, Red Bull, Burn, Gorilla и т.д.), их **цены, скидки, объёмы,
наличие и ссылки на товары**, помечает **импортные и лимитированные (редкие)**
позиции и складывает всё в отчёты: таблицу в консоли, CSV, Excel и
интерактивную HTML-страницу с фильтрами. История цен хранится в SQLite,
и при повторных прогонах видно изменение цены.

## Источники данных

| Источник | Что отдаёт | Как снимается | Нюансы |
|---|---|---|---|
| **Dina** (`dinamarket.kz`) | Полный каталог, цена и остаток конкретного магазина, старая цена/скидка, фото, ссылка | Публичный GraphQL-API без авторизации | Сеть родом из Актобе, ~10 магазинов в городе. Цены у разных магазинов могут отличаться |
| **Magnum** (`magnum.kz`) | Акционный каталог скидок, текущая и старая цена | SSR-HTML (обычный HTTP + BeautifulSoup, браузер не нужен) | Это каталог *скидок* (~150 позиций), а не весь ассортимент; цену стоит подтвердить в магазине |
| **Marwin/Meloman** (`marwin.kz`) | Самая широкая линейка импортных Monster (Польша/Великобритания): Nitro, The Doctor, Khaotic, Ultra-серия; цены и статус наличия | SSR-HTML категорийной страницы | Физический магазин в Актобе — ТРЦ Keruen City. Наличие на сайте зависит от выбранного города |
| **Anvar** (`anvar.kz`) | Упоминания товаров в промо-листовках | Разбор HTML листовок | На сайте сети нет каталога с ценами — записи идут как «наводка» без цены |
| **Веб-поиск** | Находки из поисковой выдачи (редкие импортные вкусы, обзоры, магазины) | DuckDuckGo HTML, без API-ключа; при наличии `SERPAPI_KEY` — SerpAPI | Результаты помечены «требуется проверка» |

Маркетплейсы с доставкой (Kaspi, Wildberries, Ozon) намеренно не подключены:
по задаче нужны физические магазины города. Их легко добавить как новый
источник (см. ниже).

## Установка

Нужен Python 3.10+ (проверено на 3.11).

**Linux / macOS:**

```bash
./run.sh --demo          # первый запуск сам создаст .venv и поставит зависимости
```

**Windows (PowerShell или cmd):**

```bat
run.bat --demo
```

Либо вручную на любой ОС:

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
python run.py --demo
```

`--demo` работает полностью офлайн, на сохранённых фикстурах — так можно
сначала проверить отчёты, не выходя в интернет.

## Использование

```bash
# Полный прогон по Актобе (все источники, все энергетики)
python run.py

# Сфокусироваться на Monster
python run.py --query monster

# Только редкое/эксклюзивное не дороже 2000 тг
python run.py --rare-only --max-price 2000

# Только Dina, но по всем её магазинам Актобе (а не по одному)
python run.py --source dina --all-shops
python run.py --source marwin --rare-only   # только импортные редкости Marwin

# Без веб-поиска, только физические сети
python run.py --no-web

# Посмотреть список магазинов Dina в городе и выйти
python run.py --list-shops

# Своя папка отчётов и отключение истории цен
python run.py --out my_reports --no-history
```

### Все параметры

| Параметр | Назначение |
|---|---|
| `--config config.yaml` | путь к YAML-конфигу (см. `config.example.yaml`) |
| `--demo` | офлайн-режим на фикстурах, без интернета |
| `--city Город` | переопределить город |
| `--query слово` | добавить поисковое слово (можно повторять: `--query monster --query red bull`) |
| `--source dina,magnum,anvar,web` | ограничить источники |
| `--max-price N` | максимальная цена за единицу, тенге |
| `--rare-only` | только позиции с пометкой «редкое»/«эксклюзив» |
| `--in-stock-only` | отбросить товары, которых нет в наличии (по данным Dina) |
| `--all-shops` | сканировать все магазины города в Dina |
| `--no-web` | отключить веб-поиск |
| `--no-history` | не писать историю цен в SQLite |
| `--out reports` | папка для отчётов |
| `--list-shops` | показать магазины Dina в городе |
| `--verbose` | подробный режим: пишет `reports/debug_*.log` с ответами сайтов |
| `--doctor` | диагностика пакетов и доступности сайтов |

## Как определяется редкость

Эвристики (`energy_scout/rarity.py`) считают баллы по названию:

- **импорт** (+2): маркеры «импорт», «США», «Япония», «Европа», «Германия»,
  «Корея», «Китай» и т.п.;
- **лимитированный выпуск** (+2): «лимит», «limited edition», «эксклюзив»,
  «сезонный», «снят с производства» и т.п.;
- **редкий вкус Monster** (+1): отдельный словарь экзотических линеек
  (Pipeline Punch, Ultra Fiesta, Aussie Lemonade, Nitro, Maxx, Reserve и др.);
- **новинка** (+1): слабый сигнал.

Итог: 0 баллов — `ordinary`, 1–2 — `rare`, 3+ — `exclusive`.
Словари легко редактируются под себя.

## Отчёты

После каждого прогона в папке `reports/` появляются:

- `energy_scout_ГГГГММДД_ЧЧММСС.csv` — для Excel/гугл-таблиц (разделитель `;`, UTF-8);
- `energy_scout_ГГГГММДД_ЧЧММСС.xlsx` — два листа: «Результаты» с фильтрами
  и подсветкой редкого, и «Сводка» по источникам;
- `latest_report.html` — автономная страница (открывается двойным кликом,
  интернет не нужен) с живыми фильтрами: поиск, редкость, наличие, макс. цена;
- `history.db` — SQLite с историей цен; в консоли и отчётах выводится колонка
  `Δ цены` относительно прошлого прогона.

## Запуск на iPhone / iPad

Полноценного Python в iOS нет, но есть приложения-терминалы. Рабочий вариант —
**a-Shell** (бесплатно в App Store): внутри настоящий Python 3, `pip`,
доступ к сети и файлам.

1. На GitHub нажмите **Code → Download ZIP**, распакуйте архив в «Файлах»
   и положите папку в каталог `On My iPhone → a-Shell`.
2. Откройте a-Shell и перейдите в папку проекта:
   ```
   cd Energy-Scout-main
   ```
3. Первый запуск (поставит нужные пакеты и проверит всё на демо-данных):
   ```
   sh run_ios.sh --demo
   ```
4. Боевой прогон:
   ```
   sh run_ios.sh
   sh run_ios.sh --query monster --rare-only --compact
   ```

Особенности телефона, которые уже учтены в коде:

- `--compact` включает узкую таблицу из 5 колонок (лаунчер включает его сам);
- `lxml` и `PyYAML` не обязательны: без них работает встроенный `html.parser`,
  а конфиг берётся из значений по умолчанию и флагов команды;
- без `openpyxl` Excel пропускается, но CSV и HTML создаются как обычно;
- если встроенный в a-Shell numpy сломан (частая история на Python 3.13,
  ошибка `TypeError: ... __typing_prepare_subst__`), Energy Scout сам
  отключает numpy через import-finder и открывает openpyxl в чистом
  Python-режиме — Excel продолжает работать, ничего настраивать не нужно;
- HTML-отчёт открывается из «Файлов» в Safari, CSV/XLSX — в Numbers или Excel;
- запуск по расписанию настраивается через приложение **«Команды»** (Shortcuts):
  автоматизация → действие a-Shell с командой `cd Energy-Scout-main && sh run_ios.sh`.

Если что-то не запускается — одной командой соберите диагностику
(версии пакетов и доступность всех сайтов) и пришлите вывод:

```
python3 run.py --doctor
```

`--doctor` показывает интерпретатор (`sys.executable`), статус каждого
пакета (включая отдельную проверку numpy) и HTTP-доступность всех
сайтов-источников, а также проверяет совместимый импорт openpyxl.

Проверить код без интернета можно офлайн-демонстрацией:
`python3 run.py --compact --demo`.

Альтернативы: **Pyto** (платный, тоже умеет pip и «Команды»), либо самый
комфортный для телефона вариант — Telegram-бот, запущенный на бесплатном
облачном хостинге: тогда на айфоне не нужно ничего устанавливать, только чат.

## Настройка

Скопируйте `config.example.yaml` в `config.yaml` и меняйте:

- ключевые слова и список исключений (отсекает корма, игрушки и прочий мусор);
- включение/выключение источников;
- паузу между запросами (`delay_seconds`) и таймауты;
- число поисковых запросов к вебу;
- алиасы названия города.

## Ограничения и честные предупреждения

1. **Сайты меняются.** Если Dina/Magnum поменяют вёрстку или API,
   соответствующий адаптер вернёт ошибку в сводке, но остальные источники
   продолжат работать. Точки интеграции изолированы в `energy_scout/sources/`.
   При любых ошибках или пустой выдаче запустите `python run.py --verbose` —
   в `reports/debug_*.log` запишется, что именно ответил каждый сайт
   (статусы, фрагменты ответов, сработавший поисковый движок). Веб-поиск
   сам перебирает DuckDuckGo HTML → DuckDuckGo Lite → Bing, если первый
   движок заблокирован в вашей сети.
2. **Anvar** не публикует каталог с ценами — только листовки; это ограничение
   самой сети, а не скрипта.
3. **Веб-поиск** может находить неточные/устаревшие страницы — такие записи
   помечены «требуется проверка».
4. Наличие в реальном магазине меняется быстрее, чем обновляется сайт;
   данные Dina по остаткам — лучший доступный ориентир, но не гарантия.
5. Скрипт ходит на сайты с паузами (по умолчанию 0,4 с), одним запросом
   за раз и не обходит защиты от ботов. Используйте его для личных
   покупательских целей и соблюдайте правила сайтов.

## Структура проекта

```
energy_scout/
├── cli.py               # аргументы командной строки
├── config.py            # конфиг и значения по умолчанию
├── http.py              # HTTP-клиент с ретраями + офлайн-фикстуры
├── models.py            # модель товара
├── normalize.py         # цены, объёмы, дедупликация
├── rarity.py            # эвристики редкости и бренды
├── pipeline.py          # оркестрация, фильтры, сортировка
├── sources/
│   ├── dina.py          # GraphQL Dina (магазины → категории → товары)
│   ├── magnum.py        # SSR-HTML каталога скидок
│   ├── anvar.py         # промо-листовки
│   └── websearch.py     # DuckDuckGo / SerpAPI
└── report/
    ├── console.py       # таблица в терминале
    ├── files.py         # CSV / Excel / HTML
    └── history.py       # SQLite-история цен
tests/                   # офлайн-тесты на фикстурах
run.py                   # точка входа
run.sh / run.bat         # запуск в один клик
```

### Как добавить новый источник

1. Создайте класс в `energy_scout/sources/`, унаследовав `BaseSource`
   и реализовав метод `fetch() -> SourceResult`.
2. Зарегистрируйте его в `pipeline.build_sources()` и в `SOURCE_LABELS`.
3. Добавьте фикстуру в `tests/fixtures/` и тест в `tests/test_logic.py`.

## Тесты
